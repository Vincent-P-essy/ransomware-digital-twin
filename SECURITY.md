# Security policy

## Supported version

The current `main` line is supported. This repository is a safe simulation
demonstrator, not an offensive tool or hosted production service.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue. Contact the
repository owner through the private contact method on their GitHub profile and
include the affected version, reproduction steps, impact, and suggested mitigation.
Do not include real credentials, production data, or executable samples.

An acknowledgement should arrive within seven days. Disclosure timing will be
coordinated after validation and a fix are available.

## Safe research

Use only the packaged fictional data and systems you own or are authorized to test.
Reproducing this project requires no scanning, exploitation, persistence, credential
access, destructive operation, or external target.
